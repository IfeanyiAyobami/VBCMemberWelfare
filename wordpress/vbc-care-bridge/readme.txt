VBC Guest Care Bridge 0.6.0

Read GUEST_SETUP.md in the dashboard package first.
Activate this plugin on a staging WordPress site. It remains disabled until configured.
Server configuration belongs in wp-config.php; no keys are embedded in this plugin or its HTML.
Use [vbc_guest_journey] in one Elementor Shortcode widget on a private test page.
The complete journey HTML file includes all CSS and JavaScript.
This plugin stages guest cards for staff review. It does not send emails or SMS.
