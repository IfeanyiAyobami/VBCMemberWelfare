# v4.1.1 — Original programme card layout

Saved programmes now use the original photo-led card layout: faded artwork, top-left status, top-right date, uppercase Anton title, venue/time and Create invite / Edit actions. A small View full flyer link opens the uncropped uploaded artwork. Weekly programmes show their next occurrence and recurring schedule.

No additional SQL or environment changes are required if migrations 022–024 are already installed. All v4.1 registration, storage and recurrence features remain in place. The included v4.1 manual illustrates the earlier card presentation; this note supersedes that illustration only.
